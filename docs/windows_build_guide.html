1 准备工作与依赖清单

Tauri 打包的本质是：前端(Vite/React) + Rust 后端 用系统 WebView2 渲染。Windows 上必须装齐下面三样，否则会卡在 Rust 编译或运行时。

依赖作用建议版本
Microsoft C++ 生成工具Rust 编译需要 MSVC 链接器VS 2022 生成工具 + “使用 C++ 的桌面开发”
Node.js跑 Vite / 安装依赖LTS 20 或 22（nodejs.org）
pnpm本项目包管理器任意新版本，下面用一条命令装
Rust 工具链编译 Tauri 后端（src-tauri）stable + msvc 目标
WebView2Windows 10/11 已内置；老系统需手动装见排错表
本项目已就绪：pnpm tauri 脚本、tauri.conf.json（productName=EvoSuite、打包 msi/nsis）、图标 icons/ 都在 src-tauri/ 下，无需改动即可打包。

2 安装前置工具（一次性）

A. 安装 Node.js 与 pnpm

  1. 到 nodejs.org 下载 LTS 安装包（.msi），双击安装，一路 Next。
  2. 打开 PowerShell（管理员） 或终端，安装 pnpm：
npm install -g pnpm
  1. 验证（重开一个终端后）：
node -v # 期望 v20.x 或 v22.x pnpm -v # 期望 9.x / 10.x

B. 安装 Microsoft C++ 生成工具（关键！）

  1. 下载 Visual Studio 2022 生成工具（Build Tools for Visual Studio）。
  2. 运行安装器，在工作负载里务必勾选 “使用 C++ 的桌面开发”。
  3. 右侧“安装详细信息”中确认包含：MSVC v143、Windows 10/11 SDK、C++ CMake 工具。
  4. 点“安装”，约 5–10 分钟（占用约 6 GB）。
这是 Windows 上最容易漏的一步。没装它，Rust 编译会报 “linker `link.exe` not found”。装完重启电脑再继续。

C. 安装 Rust

  1. 到 rust-lang.org/tools/install 下载 rustup-init.exe 并运行。
  2. 选择默认安装（1）即可，会自动装 stable-x86_64-pc-windows-msvc。
  3. 装完重开终端，验证：
rustc --version # 期望 rustc 1.7x.x cargo --version # 期望 cargo 1.7x.x

3 把代码放到 Windows 上

你本机是 Linux 沙箱，需要把整个 evosuite 工程目录拷到 Windows。两种方式任选其一。

  • 方式一（推荐，最稳）：U 盘 / 网盘 / 内网传输
    把 Linux 上的 /workspace/evosuite 整个文件夹复制下来，放到 Windows 的 D:\Projects\evosuite（建议路径不要含中文和空格）。
  • 方式二：Git
    在 Linux 端把工程提交到仓库，Windows 上 git clone 到本地。
只复制 evosuite/ 这一层即可。node_modules/ 和 src-tauri/target/ 不用带——它们会重新生成，且带着反而可能跨平台冲突。

放到 Windows 后，在终端进入该目录：

cd D:\Projects\evosuite

4 安装前端依赖

在工程根目录执行（首次会下载 React / Vite / Tauri CLI 等，约 1–2 分钟，需要联网）。

pnpm install
看到无报错的提示符返回即成功。本项目 package.json 里已含 "tauri": "tauri" 脚本，所以下面用 pnpm tauri 即可调用 Tauri CLI v2。

5 准备 Rust 工具链 已含于步骤②C

若你步骤②已装好 Rust，此步已自动完成，可跳过。确认 msvc 目标存在：

rustup target list --installed # 应包含 x86_64-pc-windows-msvc
Tauri 打包 Windows 安装包用到 Windows 资源编译器（rc.exe），它由步骤②B 的 “C++ 桌面开发” 工作负载提供，必须装。

6 一条命令打包（核心）

在工程根目录执行：

pnpm tauri build

这条命令会自动按顺序：

  1. 运行 pnpm build（tauri.conf.json 里的 beforeBuildCommand）→ 生成 dist/ 前端产物；
  2. 用 Cargo 编译 Rust 后端 → 约 3–8 分钟（首次最慢，会拉取并编译 Tauri 依赖）；
  3. 把前端 + 后端打包成安装包，输出到 src-tauri/target/release/bundle/。
首次编译可能要下载几百 MB 的 Rust crate，请保持联网、耐心等待。看到进度条或 “Compiling tauri …” 是正常现象，不是卡死。
看到终端最后出现 Finished 且无红色报错，即打包成功。

7 找到安装包并安装

打包成功后，安装包在：

evosuite\src-tauri\target\release\bundle\msi\ ← .msi 安装包（推荐） evosuite\src-tauri\target\release\bundle\nsis\ ← .exe 免安装版（绿色，解压即用）
  • 双击 EvoSuite_0.1.0_x64_en-US.msi → 按向导安装。
  • 开始菜单会出现 EvoSuite，打开即进入桌面应用。
  • 想直接拷给别人用，拿 nsis 里的 .exe 即可（无需安装）。

8 想先看效果：dev 模式

不想等完整打包，可先以开发模式把原生窗口跑起来（同样会编译 Rust，但热更新前端）：

pnpm tauri dev

会弹出一个真实的桌面窗口（标题 “EvoSuite · 进化与流病分析”，1280×820）。改代码后窗口自动刷新。确认手感 OK 再回到步骤⑥正式打包。

纯浏览器预览（只看外壳/可视化、不经 Rust）则更简单：pnpm dev 后浏览器打开 http://localhost:5173。

9 常见报错与对策

现象原因解决
linker `link.exe` not found 没装 MSVC 生成工具 装 “使用 C++ 的桌面开发” 工作负载（步骤②B），重启
rc.exe / Windows SDK 找不到 VS 生成工具缺 Windows SDK 在 VS Installer 里勾上 Windows 10/11 SDK 与 C++ CMake 工具
'tauri' 不是内部或外部命令 依赖未安装 回到根目录执行 pnpm install
编译卡在 Compiling tauri ... 很久 首次拉取/编译 Rust 依赖 正常现象，保持联网等待；后续会快很多
窗口空白 / WebView 报错 缺 WebView2 到微软下载 WebView2 运行时 安装
路径含中文/空格导致编译失败 部分 Rust 工具链对路径敏感 把工程放到如 D:\Projects\evosuite 纯英文路径
PowerShell 禁止脚本执行 执行策略限制 管理员运行 Set-ExecutionPolicy -Scope CurrentUser RemoteSigned
打包成功 ≠ 算法接入完成。本 MVP 的内置算法（NJ/UPGMA/K80/比对）已能离线跑通；MAFFT、IQ-TREE2 等真实引擎会在检测到本机已安装时自动调用，未安装则降级为内置实现。

一句话总览

装齐 VS C++ 生成工具 + Node + Rust → 把 evosuite 拷到 Windows → pnpm install → pnpm tauri build → 去 target/release/bundle/msi/ 拿安装包。完事。
